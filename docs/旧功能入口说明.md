当前首页接入 **189 项**原有能力、不同配置示例及公共包教学入口。已将盘点的 **175 个原独立 main** 全部接入，实际实现与 **85 个功能专属依赖库** 集中到 `lib/demos/<中文功能>/源码/`；旧路径保留包级导出与 main 转发，原有调用方仍可使用。共享工具通过已有公共引用复用，不重复复制。

本清单记录旧 Flutter 功能的源码归并、实际可达页面和验证结果；OC／Swift 对照见[原生功能对照](./原生功能对照.md)。跨平台进入与退出回归、插件编译和设备能力验收分别记录。

## 一、运行与目录约定 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

从项目根目录执行，例如：

```shell
flutter run -t lib/demos/表格等宽列/入口.dart
flutter run -t lib/demos/控制器跨页生命周期/入口.dart
```

VS Code 可打开具体中文目录下的 `入口.dart` 后运行。每个目录包含独立入口和真实源码，`sourcePath` 指向中文功能根目录入口，`implementationPath` 追溯同目录中的实现；首页复制运行命令使用 `entryPath`，两者均由[目录模型](../lib/demo_hub/legacy_catalog.dart)登记。需要 Get 导航的独立入口使用[Get 预览壳](../lib/demo_hub/legacy_support.dart)，主题和语言选择复用公共包；宿主已提供 Get 导航时直接构建页面。

## 二、当前兼容处理 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- 拖动手势使用可切换的自由/水平/垂直识别，避免原示例同时启用互斥识别器的断言；同目录源码保留原教学功能。
- 原倒计时按钮未启动退出时有未初始化 timer 问题，兼容入口使用自动启动，仍可点击暂停/恢复；兼容的独立 main 与首页共用安全实现。
- Get Controller 仅在页面需要时注册，退出只删除本页面创建且仍同一实例的 Controller，不清空其它演示状态。
- 公共刷新列表直接消费 `jobs_refresh_load`，公共安全取值直接消费 `jobs_safety_get_value`。刷新入口补齐首屏数据、API优先和退出后的异步通知保护，公共包原文件不改。
- HTTP/Dio 七种方法页复用原解析和呈现实现；目录每次先请求API，失败、超时或不可解析时回退当前请求，后续请求继续访问服务端。上传、下载及错误演示也有对应本地数据。

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| `JOBS_METHOD_API_BASE` | `http://127.0.0.1:18080` | HTTP/Dio教学服务；Android模拟器或真机传可访问主机地址 |
| `JOBS_METHOD_API_TIMEOUT_MS` | `900` | 教学请求超时毫秒数 |
| `JOBS_DEMO_API_BASE` | `http://127.0.0.1:18080` | 公共刷新示例服务，读取 `/api/demo/refresh` |
| `JOBS_DEMO_API_TIMEOUT_MS` | `900` | 公共刷新请求超时毫秒数 |

通过 `--dart-define=配置名=配置值` 传入。公共刷新响应为 `{"items":["项目1","项目2"]}`；HTTP/Dio保留原 `/api/methods` 与各方法页约定。回退响应带 `x-jobs-data-source: local-demo`，明确区分示例数据与服务响应。

## 四、原独立入口与资源隔离 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- 175 个原 main 均保留旧路径转发，并提供中文功能目录下独立入口；完整原路径、新路径、入口、迁移前 SHA256 和当前源码指纹见[源码迁移清单](./旧功能源码迁移.json)，入口关系见[盘点资料](./旧功能入口盘点.json)。
- 控制台、集合、反射、注解、单例、Isolate 等教学入口真实执行原函数并展示实际输出；异步日志可继续刷新。页面退出与重试取消该次运行创建的 Timer／周期 Timer，并关闭登记的端口、Isolate 和网络连接。
- 原 Material／Cupertino／Get 根由局部 Navigator 承载，保留 Provider 包裹、路由、参数与 Binding。Get 控制器名称按教学库隔离，退出恢复该页面临时安装的翻译。
- 旧键盘示例的 observer 强转、自动滚动退出递归、单例错误类型转换、注解伪反射、网络图片断言、图片缺失资源、剪贴板布局溢出和 EasyLocalization 外层 context 已修正，原教学目的保留。
- 视频文件示例从本地打包资源写入应用临时目录；沙盒视频移除固定设备绝对路径。Android `contentUri` 示例接受实际授权的 `content://` 输入并校验，保留错误和重新操作入口。
- 相机、原生 WebView、SQLite、视频、截图等使用明确平台条件；不支持的平台显示完整支持范围与重新加载入口，支持平台继续运行原插件实现。权限、授权内容 URI、媒体解码和真实设备硬件结果须用对应设备验证。

## 五、多语言与主题 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

119 个新增旧例目录逐项采用具体中文功能名（GetX、JSON 等技术名保留），完整功能列表见上表。

旧页面实际 `Text`、Tab、操作按钮、输入 hint／label、校验错误和动态状态统一通过[旧功能词库](../lib/demo_hub/legacy_strings.dart)响应十语切换；模板替换保留用户输入与实参数值。源码框架名、示例内容、JSON字段和控制台教学输出保留原意。词库注册入口为 `registerLegacyTranslations()`，首页和独立预览均注册。

独立预览提供白天／黑夜／跟随系统以及十语设置；局部旧 App 继承相同主题与语言。原有主题和语言教学按钮仍可操作，并同步到当前预览设置。

新增输入组合对照原生 UITextField／UITextView 的限长、焦点、格式化、校验、富文本链接、双向绑定与删除监听；横纵刷新组合提供独立四向计数和七种实际动画。输入格式化与边缘刷新协议下沉公共包公开入口 `jobs_input_tools.dart`、`jobs_edge_refresh.dart`。刷新进入与操作请求 `/api/demo/edge-refresh`，`{axis,edge,page}` JSON 参数；成功读取 `{items:[...]}`，失败沿用本地可操作数据。Lottie 资源 `assets/Lottie/JobsSignatureSlogan.json` 复用 OC 自有源文件（最近资源提交作者 Jobs），不从第三方文件派生。
