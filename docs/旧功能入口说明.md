本页追溯 **189 项**已有能力、不同配置示例及公共包教学入口，是当前首页功能的来源对账子集，首页按实际功能语义归组，不显示来源新旧标签。盘点的 **175 个原独立 main** 已接入，实际实现与 **85 个功能专属依赖库** 集中到 `lib/demos/<中文功能>/`；原 `lib/JobsDemoTools` 路径保留包级导出与main委托，原有调用方仍可使用。共享工具通过已有公共引用复用，不重复复制。

本清单记录旧 Flutter 功能的源码归并、实际可达页面和验证结果；OC／Swift 对照见[原生功能对照](./原生功能对照.md)。跨平台进入与退出回归、插件编译和设备能力验收分别记录。

## 一、运行与目录约定 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

从项目根目录执行，例如：

```shell
flutter run -t lib/demos/表格等宽列/表格等宽列.dart
flutter run -t lib/demos/控制器跨页生命周期/LifecycleDemoPage.dart
```

VS Code 直接打开表中的实现源码运行；其头注给出项目相对运行命令，导入／part指令后即为main。`sourcePath` 与 `entryPath` 同指实际实现文件，均由[目录模型](../lib/demo_hub/legacy_catalog.dart)登记；首页源码定位和复制命令直接进入实现文件。175个纯转发入口已删除，46个带实际实现的入口已按功能目录名称命名；实现和辅助源码放在功能目录同级，不再经过 `源码/`。需要Get导航的独立目标使用[Get预览壳](../lib/demo_hub/legacy_support.dart)，主题和语言选择复用公共包；宿主已提供Get导航时直接构建页面。运行仍需当前工程的pubspec、资源与辅助文件。

## 二、当前兼容处理 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- 拖动手势使用可切换的自由/水平/垂直识别，避免原示例同时启用互斥识别器的断言；同目录源码保留原教学功能。
- 原倒计时按钮未启动退出时有未初始化 timer 问题，兼容入口使用自动启动，仍可点击暂停/恢复；兼容的独立 main 与首页共用安全实现。
- Get Controller 仅在页面需要时注册，退出只删除本页面创建且仍同一实例的 Controller，不清空其它演示状态。
- 公共刷新列表直接消费 `jobs_refresh_load`，公共安全取值直接消费 `jobs_safety_get_value`。刷新入口补齐首屏数据、API优先和退出后的异步通知保护，公共包原文件不改。
- HTTP/Dio 七种方法页复用原解析和呈现实现；目录每次先请求API，失败、超时或不可解析时回退当前请求，后续请求继续访问服务端。上传、下载及错误演示也有对应本地数据。

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| `JOBS_METHOD_API_BASE` | `http://127.0.0.1:18080` | HTTP/Dio教学服务；Android模拟器或真机传可访问主机地址 |
| `JOBS_METHOD_API_TIMEOUT_MS` | `900` | 教学请求超时毫秒数 |
| `JOBS_DEMO_API_BASE` | `http://127.0.0.1:18080` | 公共刷新示例服务，读取 `/api/demo/refresh` |
| `JOBS_DEMO_API_TIMEOUT_MS` | `900` | 公共刷新请求超时毫秒数 |

通过 `--dart-define=配置名=配置值` 传入。公共刷新响应为 `{"items":["项目1","项目2"]}`；HTTP/Dio保留原 `/api/methods` 与各方法页约定。回退响应带 `x-jobs-data-source: local-demo`，明确区分示例数据与服务响应。
