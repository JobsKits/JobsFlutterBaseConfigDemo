# SDK 获取自动重试

仅供同包脚本 `source` 的函数库，调用 `jobs_sdk_retry 标题 日志文件 命令 参数…`。获取失败自动以 2、4、8、16、30 秒间隔持续重试，无次数或总时长上限；`JOBS_SDK_RETRY_DELAY` / `JOBS_SDK_RETRY_MAX_DELAY` 可调整退避秒数。真实下载输出由原命令显示，尝试与间隔追加到调用方日志；每次获取的原始输出另追加到 `<日志>.attempts.log`，即使调用方重建解析文件也不丢失前次详情。调用方重建日志时设置 `JOBS_SDK_LOG_REPLACED=1`。

调用方只传入可重复执行的 SDK 下载、安装或首次补齐步骤；业务构建、版本选择和许可不在重试范围。工具自身许可交互保留。明确权限、磁盘、架构、参数、无效版本与拒绝许可错误直接失败；Ctrl+C、TERM、HUP 终止当前获取子树。调用方单次超时应清理子树并返回 124，继续下一次；中断状态返回而不再尝试。缓存与可续传文件由原工具保留，模块不清空缓存、不修改代理、全局源或系统配置。

隔离验证使用临时假工具，覆盖先失败后成功、连续超时、取消、日志与机器输出；不执行真实 SDK 安装。
