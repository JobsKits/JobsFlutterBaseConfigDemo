开屏使用替换导航并取消计时器，返回不会再次看到开屏。开屏演示及其上方路由可见时，首页浮钟隐藏、停计时且不能命中，真正回到首页后恢复。首页右上圆圈省略号打开“搜索Demo／全部收缩或展开／设置”菜单；搜索进入独立路由，空词只显示历史或无历史占位，清空结果仍留在搜索页，取消恢复首页。搜索期间首页悬浮工具和抽屉手势临时关闭，退出保留原布局和显隐偏好。

分组标题切换收缩／展开，拖动手柄调整组或组内条目的位置；组头仅保留标题、数量和拖动柄，移除“三点 → 上移／下移”菜单。功能条目行的源码位置／复制运行命令菜单继续保留。置顶项移入独立顶部组，取消后回原组。设置可选择记住列表布局或重启还原，提供恢复默认布局。侧栏宽度与覆盖／平移方式独立选择。首页提供可全屏拖动吸边的时间按钮、左下“按”、右下旋转计时及摇动恢复的Bug调试入口；时间按钮短按进入世界时钟，长按拖动，显隐由设置控制，取代旧长按隐藏语义。

首页卡片采用Swift实际目录样式：圆角14、卡片水平10／垂直8留白，组标题／副标题17／13，行标题／副标题17／12及最小行高56；组头与行尾箭头、内部分隔和明暗表面形成层级。只调整目录骨架视觉，稳定ID、拖排、置顶、最近与折叠语义保持。

首页来源副标题为 `JobsFlutterBaseConfigDemo`。时间浮钮按当前语言、实际字体和缩放测量，保留左右16／上下10留白并限制在安全区；窄屏大字换行增高，横竖屏改变保留吸边。世界时钟是独立骨架页：当前时区置顶，全球每个有效UTC偏移选一处知名代表，巴黎／纽约优先，包含30／45分钟偏移，日期与星期按各地当地时间计算。现有 `timezone` IANA 数据处理夏令时，设备当前区展示系统名称与UTC偏移，不猜测其IANA标识。页面前台可见才每秒读取绝对时间，覆盖／后台／销毁停止，恢复立即刷新。

世界页“12小时制”开关默认关闭（24小时）；打开后所有时区立即使用带大写AM／PM的12小时表达，午夜12 AM、正午12 PM。独立持久键 `hub.worldClock12Hour` 保存选择，主应用同时发送 `worldClock12Hour` 偏好PUT，离线不影响本地生效；切换保留滚动位置，首页浮钟仍为24小时。骨架页不登记为Demo，不增加功能目录计数或最近记录；异常有完整空态与重新加载。日期库缺少藏文符号时使用本地藏文公历字段与星期，其余九语使用Intl。

侧栏“最近使用”展示独立列表，始终展开并按最近打开的稳定 ID 顺序排列，不受首页分组折叠、置顶和服务端目录排序影响，不提供手工拖排。普通目录、搜索结果、最近列表打开功能共用记录逻辑：前插去重、最多 30 项、重启恢复，忽略不再注册的 ID；返回保留打开来源。无记录时显示完整空态与重新加载。侧栏收藏入口和行菜单收藏项已移除；旧 `hub.favorites` 数据不主动删除，也不再读取、写入或发送收藏偏好。

全局设置提供主题、十语言和“全局控件样式 → 下拉刷新 → Flutter 默认／Jobs 封装”，另有默认开启的刷新触觉／声音两个独立开关，本地持久化并随首页偏好PUT。普通列表读取该偏好；专门演示某种第三方／原生刷新的教学页保留目标组件。首页与公共适配使用 `JobsRefreshScrollPhysics`：基于 `BouncingScrollPhysics` 保留跟手阻尼与松手回弹，越界最大120逻辑像素，短列表仍能下拉。默认纵向保留Material提示，Jobs使用双球与阶段／结果文案；横向使用边缘指示实现。

Foundation与 `JobsRefreshByPub` 分页列表共用 `JobsEdgeRefreshController`，支持横纵两端、reverse／RTL及刷新加载角色互换；刷新和加载互斥，失败保留已成功数据与页码，可继续重试，“没有更多”只阻止继续加载。指示区分别显示上次成功刷新／加载时间，首次明确无记录；传入稳定 `historyKey` 后分别写入 `jobs_refresh.<historyKey>.refresh / .load`，失败不更新时间，首页按目录筛选隔离。运行时保留纵向76／横向112逻辑像素指示区，随字号调整且不超过120；横向按实际揭示宽自然换行、完整状态与历史按可用高整体scaleDown，不用ellipsis省略时间，纵向保持原布局。阈值以下随手势逐渐揭示，完成态停留350ms，再用250ms收回。

Jobs有效手动开始、成功和失败各反馈一次，自动初载安静；后台、被路由覆盖和销毁不补放，关闭声音立即停止。三份提示音为Jobs原创本地WAV，以 `AssetSource` 播放，iOS使用ambient并混音、遵循设备静音行为，不依赖Darwin不支持的字节音源。触觉或音频设备缺失不影响请求与视觉状态，真机听感／手感另验。完整参数、来源与验证边界见[刷新与公共入口盘点](../项目相关报告/刷新交互与Demo公共入口资产盘点.md)。最近使用、搜索历史、菜单及外观偏好持久化。界面复用现有图标与指定原生Bug素材，出处和许可随本地资源保留；网络图片示例先显示打包资源，失败保留本地兜底。

## 二、运行与新增功能 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

在项目根目录通过 [**FVM**](https://fvm.app/) 管理 [**Flutter**](https://flutter.dev/)：`.fvmrc` 绑定 `stable` 频道，编辑器使用 `.fvm/flutter_sdk`，CI 解析同一频道的当次最新稳定版并核对实际版本。Flutter `3.50.0` / Dart `3.14.0` 为已验基线，`pubspec.yaml` 的版本范围继续作为兼容下限。先执行 `fvm install` 与 `fvm flutter pub get`，再运行下列命令；后续稳定 SDK 更新须重新验证，不将频道绑定等同于每次运行自动升级。官方发布信息见[发布说明](https://docs.flutter.dev/release/release-notes)。

```shell
fvm flutter run -t lib/main.dart
fvm flutter run -t lib/demos/异形按钮/异形按钮.dart
fvm flutter test
fvm flutter analyze --no-fatal-infos
fvm flutter build ios --simulator --debug
```

通过初始化脚本刷新已绑定的 `stable` SDK；它在无工程的临时目录调用 SDK 实际入口升级，隔离业务依赖锁。普通运行不自动升级，也不修改本机独立全局 SDK。

VS Code 的“运行当前 Demo 文件”直接运行实际实现源码：头注给出项目相对 `flutter run -t` 命令，顶层 `main()` 放在导入／part指令之后，具体类型声明之前。注册目录中的 `sourcePath` 与 `entryPath` 同指该文件，首页源码定位与复制命令也保持一致。迁移时核查的300个主／独立运行文件包括175个实现源码、46个自身承载实现的入口文件和79个独立或转发文件，不能等同页面数量；这是并行OCR补main之前的历史基线，不作为当前文件总数。另175个纯兼容入口只保留export与main委托，88个辅助文件不添加无意义main，三份生成part保持原字节。

新增页面同时加入一个注册目录，填写唯一 ID、功能语义名称、分组、关键词、实际源码相对路径及 WidgetBuilder；不使用“旧例·”目录前缀、来源桶或“原有完整示例”标签。主 App 直接push页面；独立文件由 `JobsDemoApp` 包裹。具有GetX、Provider等依赖的页面由局部运行适配器初始化依赖和路由；原教学main的runApp在作用域内捕获，退出时释放计时器、监听和连接。独立文件依然使用本工程的pubspec、资源与公共辅助库，不表示脱离依赖也能单文件运行。

所有已注册Demo由 `JobsDemoAppBar / JobsDemoActions / JobsDemoActionHost` 提供唯一右上入口：无其它动作时直接切白天／黑夜，有清空、重试、撤销等动作时收进同一菜单，原回调与禁用态保留。按钮或菜单主题项显示下一行为；嵌套Material／Cupertino／GetX容器、主App push与源码独立main共用同一设置，不叠加第二个主题按钮。新增维护页面应复用此入口，第三方和所有权不明源码通过壳适配。

完整“演示设置”仍可选择十语及白天／黑夜／跟随系统，主App可从全局设置切换。操作按钮、输入提示和状态词接入实际十语，语言与主题保持响应式；代码名、教学数据和控制台输出保留教学含义。藏语业务词库由项目提供；Flutter 未内置藏语的系统 Material／Cupertino 控件使用英语回退。

## 三、API 与离线回退 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

首页立即绘制随包完整目录，同时 GET `api/demos`；成功响应形如 `{"ids":["calendar","handwriting"]}` 用于排序，只识别本地已经注册的功能，不能远程注入 Dart 页面，也不会删除原有功能。每次重新加载都会正常请求。偏好写入先在本地生效，再 PUT `api/demo-preferences/{key}`，JSON 为 `{"value":...}`。后续操作继续尝试服务端，不锁死到离线模式。

默认基址为 `http://localhost:8080/`，超时 900ms，失败／超时／解析失败保留本地目录及可演示操作。本工程不包含该服务端；这不是后台服务已部署的声明。用 `--dart-define=DEMO_API_BASE=https://example.com/` 指定实际服务地址；手机上的 localhost 指手机自身，连接开发机须传入设备可访问地址。Web 跨域和平台网络策略按实际部署配置，不为演示全局放开安全限制。

无服务器时直接运行即为离线预览。空列表提供完整占位和重新加载；无结果提供清空搜索；图片先用本地打包资源，指定网络图片失败时保留本地兜底；图标页另可观测实际内存／磁盘缓存和取消行为。旧网络与微应用示例同样采用短超时／本地回退，硬件入口按真实权限与支持状态反馈。
