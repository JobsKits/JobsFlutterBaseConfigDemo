## 一、运行与模块边界 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- 首页注册表：`../lib/demo_hub/ui_parity_catalog.dart`，包含34个实际页面；每页统一位于自己的中文目录，`入口.dart` 包含顶层 `main()`。
- 独立运行：在项目根执行 `flutter run -t lib/demos/朋友圈浏览/朋友圈浏览.dart`，其它页面同理；不通过调用其它 Demo 的 `main()` 替换宿主应用。
- 使用公共 `JobsDemoApp` 预览壳，十语言及白天／黑夜／跟随系统设置可用。页面文案词库为 `../lib/demo_hub/ui_parity_strings.dart`；主目录可注册 `uiParityTranslations`。
- 数据读写优先请求 `DEMO_API_BASE` 指定的服务端，默认 `http://localhost:8080/`，GET／PUT `api/ui-demos/{key}`，请求／响应结构为 `{"value":...}`。900ms超时后保留本地数据，下一次操作继续请求。成功响应的数据会替换演示值，乱序旧写响应不会覆盖较新值。
- 只读主题／绘图／输入事件等计算演示无需伪造后台请求；帖子、评论树、资料、草稿、消息、购物车、卡片状态和选择偏好提供实际请求与本地持久化。

## 三、资源与语义边界 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

图片复用项目已有 `assets/Images/flower.png` 与轮播资源；JobsIconfont单独复用原生字体和Alibaba官方图片，随包首帧／失败兜底，来源、SHA-256和许可边界见 [资源说明](../JobsByPubs/JobsDemoFoundationByPub/assets/iconfont/README.md)。区号数值沿用 Swift 自有 Pod 的 `sortedNameEN.plist`，地名由 Apple Foundation `Locale` 十语数据生成并随 Dart 编译，运行不依赖本机路径。Lottie轨道是Jobs自建向量动画JSON，无远程素材依赖。Markdown使用 `flutter_markdown_plus` 的GFM渲染；它不执行内联HTML或脚本。

聊天、认证、购物车和红包都是功能教学数据，不表示真实消息已送达、账户已认证或发生资金交易。草稿新选视频以≤2MB数据URI保存实际字节，浏览器直接解码，原生预览临时落盘给系统播放器，不再只保存易失效blob路径。旧草稿中的历史外部文件引用仍依赖原文件存在。

## 四、验证 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

`../test/ui_parity_test.dart` 与 `../test/ui_parity_details_test.dart` 的93项测试全部通过，覆盖34页在320×568、德语1.6倍字体的明暗挂载／退出，以及十语词库、购物车、拖卡、区号、push/pop、认证、评论树、API恢复／乱序保护、字体缓存与复用取消、PNG像素尺寸、通知队列、按钮状态、交互Label、数字插值、Sheet／Popover、Texture追加及跑马灯与联动菜单。定向静态分析不压制SDK入口弃用信息，不改变第三方源码。

```shell
flutter test --no-pub test/ui_parity_test.dart test/ui_parity_details_test.dart
```

播放器iOS走真实 `AVPlayerViewController`，Android走原生播放器；iOS流量为播放器accessLog，Android明确展示应用接收流量，不把应用总流量假称单视频消耗。Web使用实际 `video_player`，原生系统PiP、网络流量等按平台能力开放。JobsIconfont的分享在iOS／Android调用系统分享面板，浏览器用 `navigator.share`，不支持时明确反馈。

所有图片选取、文件导入及外部URL打开仍由平台权限和实际资源决定；这些原生系统交互应在目标设备验证。主 App 全量编译、最终功能对照和设备验证由根工程统一执行，不将Widget测试等同于真机权限验收。
