## 一、<span id="scope">范围、方法与结论</span>

本页于 2026-11-15 只读盘点 `Flutter`、`FlutterDemo/Lym_Flutter_Demo` 的实际入口，并核对 `FlutterDemo/51`、`FlutterDemo/SG` 全部现存 pubspec、本地 path、Git 声明、资源目录、字体与生成 part。来源未运行 `pub get`、安装、升级或修复；未读取／回显账户密钥。目标使用已核实的 Flutter 3.50.0／Dart 3.14.0，保留 `.fvmrc` 的 stable 策略。

`Flutter` 与目标均有 `.codegraph`，已先使用 `codegraph_explore(projectPath: ...)` 核对入口／公共封装；其它来源未初始化索引。之后按当前文件核查，避免把索引的符号匹配或旧 README 数量当成覆盖证明。来源提交为 Flutter `5bdeac7`、FlutterDemo 父仓 `6debfed`。

结论：基础 Flutter 的大部分教学能力已经覆盖；Lym 的真实价值在嵌套拖拽、麦位声浪及礼物连击表现，IM／RTC 服务层仍是空类或协议占位。新增以行为差集为准，不能把所有旧页重新注册一遍。本轮已实现五项交互差集，并在现有播放器页加入当前事件可以证明的质量观测与源隔离恢复。完整首帧／掉帧、字幕／音轨、磁盘预取仍需后续原生工作量，不把当前就绪事件冒充解码帧。

51 的若干中文 package URI 使用 percent 编码；按 Dart URI 规则解码后都能定位，不能把这些14处编码路径误报为文件缺失。SG 的真实失效样例是 `lib/pages/activity/a_widget/activity_progress_bar_widget.dart:4` 中 `../../../../services/theme/theme_service.dart`，会解析到根 `services`，而实际在 `lib/services`；`sport_event_ranking` 一组亦多一层 `../`。

五页使用宿主已具备的十语言与白天／黑夜／跟随系统主题设置，不另套 App。各页有独立 `main()`；列表均有完整空态与重载入口。新应用层 [InteractionRepository](../lib/demo_hub/interaction_support.dart) 在进入／重载 GET、写操作 PUT `api/curated-interactions/<key>`，请求与响应均以 `value` 包装；`DEMO_API_BASE` 由现工程约定注入，默认 localhost，超时默认 650ms，可用 `INTERACTION_API_TIMEOUT_MS` 调整。首屏本地状态立即显示，失败或格式不符继续本地演示，后续成功响应覆盖；没有服务器不阻止预览，也没有源仓运行依赖。五页业务数据不自行写 SharedPreferences。

当前原生播放器协议没有 requestID，本轮通过每次加载独立 PlatformView key／viewId 隔离源事件；旧视图按 Flutter 生命周期销毁。就绪与进度事件不等于首个已绘制解码帧，原生没有显式缓冲事件，页面不会计算假卡顿率／掉帧率。真实 iOS／Android 解码、PiP 与弱网仍需设备验收。
