## 🔥 <span id="前言">前言</span>

本清单来自 OC 新旧工程首页注册数据、Swift UIKit 的 `RootListVC.makeDemo2D()` 与 SwiftUI 的 `DemoFeature`。每行均保留目标类型、源文件和原生分组；条件编译条目单独标出。已核对实际页面动作和子功能，并分别记录交互回归、平台代码编译与设备条件。机器可读清单见 [native_feature_inventory.json](./native_feature_inventory.json)。

## 一、<span id="scope">盘点范围</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

| 原生工程 | 首页注册入口数 | 口径 |
| --- | ---: | --- |
| OC 新工程 | 116 | 含 DEBUG 条目；国家区号由独立工厂加入 |
| OC 老工程 | 116 | 保留主工程集成形态，不改 Pod 依赖 |
| Swift UIKit | 135 | 含 FMDB／WCDB 二选一、真机 Unity 与 DEBUG 条目 |
| SwiftUI | 18 | 含 DEBUG 调试面板 |

数量是四个注册表各自的条目数；同名、同能力、多层子入口和跨工程重复没有被算作独立产品能力。同一入口内的播放器本地／远程／信息流／浮窗、马赛克整图／涂抹、文字布局、按钮状态、刷新组合等已按实际动作展开到相应 Flutter 页面。

- 首页共 **281 个功能入口**：189 个原有能力及配置入口、14 个平行交互入口、7 个算法／基础能力、16 个数据与微应用、7 个补充实验、34 个 UI 对齐入口、13 个平台入口、1 个真实双引擎往返入口。保留原 Flutter 功能与旧路径转发。
- 通用组件位于 [JobsDemoFoundationByPub](../JobsByPubs/JobsDemoFoundationByPub/)，数据与桥接运行时位于 [JobsLabRuntimeByPub](../JobsByPubs/JobsLabRuntimeByPub/)，原生能力位于 [JobsPlatformLabByPub](../JobsByPubs/JobsPlatformLabByPub/)。每个功能对应中文目录和独立 main。
- AR／BLE／CoreMotion、录音／RTMP、PDF、播放器全屏／PiP、小组件、动态图标、多窗口及 Objective-C 方法补丁有真实原生实现；不支持的平台和设备条件有明确反馈。Unity 沿用原生工程的 iOS 真机 arm64 导出，不把模拟器说明页作为 Unity 运行成功。
- UIKit／SwiftUI 布局、PromiseKit、SPM、数据库等按 Dart／Flutter 生态实现对应用途。Future 五种编排、pub 资源／命令入口、持久化 CRUD 是实际运行演示；Objective-C 动态类与 IMP 回滚，以及原生宿主打开第二 FlutterEngine 均走真实原生代码。
- 藏语业务字形随包提供，十种语言与白天／黑夜／跟随系统可切换；系统控件使用 Flutter 官方支持的语言，藏语系统控件按框架规则回退英语。
